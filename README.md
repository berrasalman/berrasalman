Klasik yılan oyununun modern, neon renkli ve mobil uyumlu bir versiyonu. Yemleri topla, yılanı büyüt, kendi rekorunu geçmeye çalış!

**Oyunun özellikleri:** Puan ve rekor takibi, giderek hızlanan oyun, duraklatma ve yeniden başlatma, klavye ve dokunmatik kontroller. Oyun **HTML5 Canvas, CSS ve JavaScript** ile hazırlanmıştır; ek paket kurulumu gerektirmez.

| Kontrol | Görevi |
|:---:|---|
| `↑` `↓` `←` `→` | Yılanı yönlendir |
| `W` `A` `S` `D` | Alternatif yön tuşları |
| `Boşluk` | Duraklat / devam et |
| 📱 Kaydırma veya ekrandaki tuşlar | Telefonda oyna |

> **Not:** GitHub, README içinde JavaScript oyunu çalıştırmaz. Yukarıdaki hareketli GIF doğrudan README'de görünür. Gerçek oyun `snake-game/index.html` dosyasındadır ve GitHub Pages açılınca **OYUNU OYNA** bağlantısından çalışır.

<details>
  <summary><strong>⚙️ README, banner, oyun ve animasyon nasıl kurulur?</strong></summary>

  **1.** GitHub'da kullanıcı adınla **aynı adlı, herkese açık bir depo** oluştur. Örneğin kullanıcı adı `berra123` ise depo adı da `berra123` olmalı.

  **2.** Bu paketteki dosyaları klasör yapısını bozmadan o depoya yükle:

  ```text
  README.md
  assets/
    berra-salman-banner.png
    snake-preview.gif
  snake-game/
    index.html
  .github/
    workflows/
      snake.yml
  ```

  **3.** Bu README'deki bütün `GITHUB_USERNAME` ifadelerini gerçek GitHub kullanıcı adıyla değiştir. Aksi hâlde oyun bağlantısı ve katkı yılanı çalışmaz.

  **4.** Gerçek yılan oyununu yayınlamak için `Settings → Pages → Build and deployment` bölümünde `Deploy from a branch`, varsayılan ana dal ve `/ (root)` klasörünü seç. Ardından oyun `https://GITHUB_USERNAME.github.io/GITHUB_USERNAME/snake-game/` adresinde yayınlanabilir.

  **5.** Katkı yılanı için `Actions → Generate contribution snake → Run workflow` adımlarını izle. İş akışının repoya yazabilmesi için gerekirse `Settings → Actions → General → Workflow permissions → Read and write permissions` ayarını aç.

  **6.** İş akışı başarılı olduğunda `output` dalında yılan SVG'leri oluşur ve katkı yılanı açılır. `snake.yml` günlük otomatik yenileme için ayarlanmıştır.

  **Banner neden ayrı dosya?** GitHub README, özel görseli dosya adıyla çağırır. `assets/berra-salman-banner.png` yüklenmezse README'deki banner görünmez. Yani tek README yeterlidir, ancak görsellerin de aynı depoda bulunması gerekir.
</details>
